Welcome to SpankVANC

Route broadcast video and audio, monitor captions, and control caption and SCTE policies from a browser on your PC.

Windows 11 x64 · Experimental · Start with a test route. Python is included. FFmpeg, Blackmagic drivers and the DeckLink SDK are separate.

1. Prepare your card and media engine

  1. Install a compatible Blackmagic Desktop Video driver. Restart if requested. Confirm your card appears in Desktop Video Setup and check a known SDI picture in Media Express. Close Media Express afterward.
  2. For basic SDI capture, obtain a Windows x64 FFmpeg with DeckLink support. The complete guide describes an optional third-party download. Extract all its files into a permanent folder and locate ffmpeg.exe. A normal FFmpeg without DeckLink can still handle file/network routes.
  3. Keep a working driver for your exact card. Original Duo and Duo 2 have different connector capabilities.

2. Open the app

  1. Extract the entire Windows App ZIP into a writable folder, such as Documents. Open the extracted SpankVANC-Windows folder.
  2. Double-click Start SpankVANC.cmd. When asked, drag your ffmpeg.exe into the console and press Enter.
  3. Keep the console open. The browser should open http://127.0.0.1:8877 on this PC. Enter that address yourself if needed.

Activate your license

Enter your issued key under Application license in the browser and click Activate key. It unlocks 30 days from first activation. Internet is required at startup and during use. Expiry, revocation or a failed online check stops routes and source monitoring. Re-entering the same key does not restart the timer. See docs/LICENSING.md for renewal and privacy details.

3. Make a short recording

  1. Select the detected DeckLink input and the mode matching your SDI source. For example, Hi59 means 1080i59.94 fields per second.
  2. Start with the local TS file output and a new filename. Set SCTE to Strip and keep GPO disabled. Choose Captions Pass if supported, otherwise Strip for this first video/audio test.
  3. Check route readiness, resolve any listed requirements, then Start. Record briefly, Stop, and play the file in a TS-capable player.

A playable picture does not verify caption rendering or SCTE timing. Check those with a suitable receiver.

4. Add the features you need

Caption monitoring, SDI output, SCTE conversion and generated captions require the local extended engine. A stock DeckLink FFmpeg does not include these patches.

  1. Follow Part B of the beginner guide: install Ubuntu 24.04 in WSL and obtain the DeckLink SDK 12.8 Win/include files.
  2. Double-click Build Extended Capture.cmd, supply that SDK folder, review its actions, and type BUILD. It downloads tools/source, compiles on your PC, verifies the engine and saves its path. Allow time and several GB of storage.
  3. Restart SpankVANC after a successful build. For SDI output, configure an output connector in Desktop Video Setup and select a different port from the input.
  4. For optional live speech captions, follow Whisper installation from scratch. This needs a separate Python with Whisper/PyTorch. Select audioWhisper replacement per output. Recognition adds lag; program A/V stays live.

The engine, SDK and drivers are not in this ZIP. The pinned nonfree engine stays local; public downloads contain the app and build support.

Help and upgrades

Configure FFmpeg.cmd changes the general engine. Diagnostics.cmd writes capability reports. The app's Activity → Engine log explains route failures.

For upgrades, stop the old app and extract the new ZIP into a fresh folder. Keep the old folder for rollback. Locally copy settings.json and runtime/route.json if desired. Keep the old engine folder available: saved paths can point there. Rebuild the engine when release notes require it.

Full online guides: Windows installation · SDI and SCTE · Whisper.
