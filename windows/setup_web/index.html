Install and build

Setup downloads a separate Python, Torch, Whisper and a speech model. It prepares its own Linux build environment and compiles your media engine on this PC. Existing Python installations and Linux distributions stay separate.

Allow 12 GB of free space, Internet access, and potentially an hour or more. Windows may ask for administrator approval and a restart. After restarting, double-click Finish SpankVANC Setup on the desktop to continue.
