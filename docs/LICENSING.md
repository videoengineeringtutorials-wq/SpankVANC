# Open-source license and application access (0.12.0)

SpankVANC is MIT-licensed open source. No activation key, registration, trial
timer or online license verification is required. Routes and source monitoring
remain available without contacting a licensing service.

Versions 0.10.0 through 0.11.4 required online activation. That client, its UI,
API endpoints and periodic enforcement were removed in 0.12.0. Old license.json
files are ignored and can be deleted.

Internet is needed to download setup dependencies and for network routes that
use Internet services. Local routes do not require Internet access.

See the root LICENSE for the MIT terms. Third-party dependency licenses and
redistribution requirements remain documented in THIRD_PARTY_NOTICES.md and
[REDISTRIBUTION.md](REDISTRIBUTION.md).
